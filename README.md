# ApkIn

複数のAndroid端末に、同じAPKファイルを一括インストールするためのMac用ツールです。

## 対応環境

- **macOS 11 (Big Sur) 以降**
- **Apple Silicon (M1以降) Mac専用**
  - Intel Macでは動作しません。

## 初回起動時に必要な作業

### 1. 「開発元が未確認」の警告への対応

このアプリはApple Developer証明書による正式な署名がされていないため、初回起動時にmacOSのセキュリティ機能（Gatekeeper）が警告を表示します。

1. Finderで `ApkIn.app` を **右クリック（またはControlキーを押しながらクリック）**
2. メニューから「**開く**」を選択
3. 表示された確認ダイアログでも「**開く**」を選択

この手順は初回のみ必要です。2回目以降は通常のダブルクリックで起動できます。

> ダブルクリックで開こうとすると「壊れているため開けません」等のメッセージが出る場合がありますが、上記の右クリック→「開く」の手順で回避できます。

### 2. Androidデバイス側でのUSBデバッグ許可

初めてMacにUSB接続するAndroid端末では、端末の画面に「**USBデバッグを許可しますか？**」という確認ダイアログが表示されます。「許可」をタップしてください。

- 許可する前に「デバイスリスト更新」を押すと、その端末は一覧に表示されません（`unauthorized` として除外されます）。
- 端末側で許可した後、もう一度「デバイスリスト更新」を押すと一覧に表示されるようになります。

### 3. インターネット接続について

このアプリはインターネット接続がなくても動作します。APKの書き込みは同梱の`adb`バイナリを使ってUSB経由で行われるため、オフライン環境で問題なく利用できます。

## 基本的な使い方

1. 「APKファイルを選択」から書き込みたいAPKファイルを選ぶ（ドラッグ&ドロップも可）
2. Android端末をMacにUSB接続し、「デバイスリスト更新」を押す
3. 書き込み先の端末にチェックを入れる（「すべて選択」も利用可）
4. 「選択したデバイスに書き込み」を押す
5. 画面下部のログと、各端末のチェックボックス横のアイコン（✅成功 / ❌失敗）で結果を確認する

## 動作の仕組み（開発者向け）

- Python + Tkinterで実装し、PyInstallerで`.app`にビルドしています。
- Google公式の`adb`バイナリを`.app`内に同梱しており、別途Android SDKやplatform-toolsをインストールする必要はありません。
- ビルド方法は [build_app.sh](build_app.sh) を参照してください。
